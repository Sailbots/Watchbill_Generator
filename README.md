# Watchbill Generator
An automated watchbill generator intended for creating Navy watchbills. Very customizable; able to add/remove sailors, watchstaions, or departments; change daily watch lengths; track leave days, holidays, even daylight savings time shifts; audit changes; and more.
# Try it out by clicking here: https://sailbots.github.io/Watchbill_Generator/
# How to download & employ
The Watchbill-Generating app itself is within the "index.html" file. Highlight the file "index.html", then click the little button that says "Download Raw File". Connectivity is not required to use the app. Sometimes, Outlook and Edge will get concerned about downloading or sending an HTML file. Changing the ".html" to ".txt" will prevent this; you can then move or save the file, then change it back to ".html" when you're ready to use.
